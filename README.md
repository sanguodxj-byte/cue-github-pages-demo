# 炮塔组合动画预览服务

把 `需求及素材/炮塔/` 里的炮塔部件**层叠组合**起来，在浏览器里测**炮台动画效果**
（瞄准旋转 / 自动扫描 / 开火后坐 + 炮口闪光 + 弹丸），并附带**图片内容检查**面板。

## 启动

```bash
cd tools/turret-preview
python -B serve.py            # 默认 http://127.0.0.1:8137/index.html，自动开浏览器
python -B serve.py --port 9000 --no-browser
```

> 也可以直接双击 `index.html`（`<script src>` 方式读数据，`file://` 也能加载图片；
> 只是 canvas 取像素会被浏览器 CORS 拦，检查面板用的是构建期算好的静态数据，不受影响）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 画布内移动鼠标 | 瞄准模式=「跟随鼠标」时，炮塔顶部实时转向光标 |
| 点击画布 / <kbd>空格</kbd> | 开火（后坐 + 炮口闪光 + 弹丸） |
| <kbd>R</kbd> | 复位全部校准与状态 |
| 「自动扫描」 | 炮口左右摆动，模拟巡逻扫描 |
| 「仅炮管」/「整体」 | 决定旋转的是只有炮管，还是主体+炮管一起转 |
| 图层行点击 | 单独查看该层（solo），再点取消 |
| 「按 bbox 居中各层」 | 用每层透明包围盒中心对齐到 1024 画布中心，快速消除偏移 |
| pivot X/Y | 旋转中心，默认 (512,512)=底座圆心 |
| 格宽 | 叠加 RimWorld 格子参考网格，判断实际占地（0=关） |

## 目录

```
tools/turret-preview/
├── index.html          # 预览服务页面（层叠组合 + 动画 + 校准 + 图片检查）
├── serve.py            # 本地 HTTP 服务
├── build_preview.py    # 归档贴图 + 像素级检查 + 生成合成图（改动素材后重跑）
├── look.py             # 多图读图：把多张图一次性发给视觉模型对比判读（走平台 VISION_* 接口）
├── assets/             # ASCII 名贴图副本 + data.js（检查数据，构建期生成）
└── out/                # 合成底图 / 透明检查接触表（构建期生成）
```

改动素材后重新生成：

```bash
python -B build_preview.py
```

### 判读结论（组合口径）

- **底座**：`bbox` 精确落在 (48,48)–(976,976)，中心 **(512,512)** —— 这就是炮塔的旋转中心，
  预览里 pivot 默认取 (512,512) 与之重合。
- **炮塔1**＝底座 + 炮塔1主体 + 炮塔1炮管。主体与炮管**垂直中心都在 y=512**，同画布直接叠加即可，
  默认偏移 0；炮管 `bbox` 偏左（x 30–644，质心 346），是一条**朝左**的炮管，配合脚本会把
  「整体旋转」的零点定义在 180°（朝左）。
- **炮塔2**＝底座 + 炮塔2主体；其主体 `bbox` 几乎占满整幅宽（14–1010），左右都有横向炮管结构，
  故预览给了**左右两个炮口**，开火时同时喷火。
- **炮管是两段拼成的**：`炮塔1_主体.png` 里 y≈448–576 有一条横贯画布 (x=0→915) 的水平长条，
  其中**靠炮身（后面）的一段就是"另一截炮管/加长段"**；`炮塔1_炮管.png` 是**带炮口的前段**（炮口在最左端）。
  两段同画布叠加（默认偏移 0）即构成完整长炮管。主体横条左端贴到画布边缘是该段本身画到边界，
  **不是"裁切事故"**；真正出图时仍建议四周留 ≥16px 安全边。
- 建造图标均为 128²，供游戏内建造菜单用；`bbox` 同样贴边（126/127），属正常图标裁切。

## 预览尺寸

- 画布默认 **980×980**，默认缩放 **0.90**（炮塔约占 ~835px；早前是 620 / 0.60，此次明显放大）。
  缩放滑杆 30%–130%，画布 `max-width:100%` 随窗口自适应。

## 视觉读图复核（2026-10-12）

本环境**单图读图不可用**，读图一律走**多图视觉模式**（`look.py`，走 `.env` 的 `VISION_*` 凭据）：

- **炮塔1 炮管 = 两段**：`炮塔1_主体.png` 内那条水平长条是**靠炮身后侧的加长段**；
  `炮塔1_炮管.png` 是**带炮口的前段**（炮口在最左端）。主体横条**最左端为平切端（无炮口孔）**，
  证明它并非炮口，而是与炮管前段拼接的加长段。
- 两段同画布叠加后炮管贯通、中线对齐，默认偏移 0 即可；需要更自然的拼缝可用图层行 dx/dy 微调。
- 合成底图 `out/composite_turret*.png` 已**四周留白 96px + 1.5× 放大（1824²）**，避免贴边"裁断"观感。

## 说明

- 预览用**原生 1024 画布**做世界坐标，所有层默认居中对齐；如某层对位不准，用图层行的 **dx/dy**
  微调，或点「按 bbox 居中各层」。
- `assets/*.png` 是 `需求及素材/炮塔/` 的 ASCII 名副本（避免中文名在 URL/服务器上的编码问题），
  **源文件未被改动**。原始中文名见上表与 `assets/data.js` 的 `orig` 字段。
- 若要把预览接进游戏真实贴图流程，需要按 RimWorld 的 `GraphicData` / `turretTop` 规则再做缩放与
  pivot 对齐，本服务只负责**看得见的合成与动画验证**，不写入 Mod 的 Def。
